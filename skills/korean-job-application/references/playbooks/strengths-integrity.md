# Q09 성격 장단점 / Q10 윤리·책임

공개 사례는 질문과 답변의 짧은 관찰이며, 답변 전문·지원자 신원·문장을 재사용하지 않는다. 문항이 장단점과 성장·가치관을 함께 묻더라도 요구별 근거를 나누어 답한다. 사실이 충분하면 바로 초안을 쓰고, 해석을 바꿀 빈칸만 묻는다.

## Q09 성격 장단점

### 실제 질문 요구와 연결

- [MQ05](../cases/manufacturing-quality.md#mq05--현대파워텍--연구개발--2013-하반기)는 장점·약점과 보완을 실제로 요구한다. 장점의 추가 조사·질문·발표와 약점 때문에 팀 참여가 줄었던 결과를 분리해 썼다.
- [SS03](../cases/sales-service.md#ss03--하나머티리얼즈--국내영업--2023-상반기)는 경청·꼼꼼함을 상세페이지 분석·전표 확인에, 느린 처리를 일정 기록과 마감에 연결한다.
- [BH05](../cases/business-hr.md#bh05--kt-cs--교육운영--2023-상반기)는 실수 뒤 스트레스가 오래 가는 단점을 명시하고 기록·생활 습관으로 대응한다. 장단점 결합 문항을 성과담으로 축소하지 않는 사례다.

### 의도와 재료

독자는 좋은 형용사 목록이 아니라 업무·협업에 영향을 주는 실제 경향을 자각하고 조절하는지 본다. 장점 하나의 행동 근거, 실제 약점과 그 영향, 이미 한 보완 행동, 남은 한계 또는 점검 방식을 받는다. 약점은 치명적 고백을 강요하는 문항이 아니라 정직한 자기 인식 문항이다. 다만 직무의 필수 안전·법규 준수와 직접 충돌하는 약점은 확인 없이 가볍게 쓰지 않는다.

### 가능한 논증 순서

1. 장점 → 그것이 도움이 된 장면 → 단점 → 불편/실수 → 현재의 보완 행동과 남은 점검.
2. 단점과 보완을 먼저 → 장점은 별도 장면으로 짧게. 질문이 약점 중심이면 장점 비중을 억지로 맞추지 않는다.

### 쓰기와 수리

“완벽주의라 일이 느리지만 꼼꼼합니다”처럼 약점을 장점으로 위장하지 않는다. 대신 “세부 확인을 오래 해 첫 초안 제출이 늦어진 적이 있습니다. 이후 확인 항목과 마감 시각을 나누어 동료에게 중간본을 먼저 공유합니다”처럼 실제 불편과 대응을 함께 쓴다. 완전히 해결됐다는 근거가 없으면 `극복했다` 대신 현재의 조절 방식과 남은 주의를 쓴다.

초안의 장점이 성격 단어뿐이면 행동·산출물·피드백 중 확인된 근거 하나를 붙인다. 약점이 없거나 가짜 미덕이면 영향이 있었던 사실을 묻고, 없으면 단정적인 장단점 진술을 피한 작업 초안으로 남긴다. 타인의 평가·팀 성과를 자신의 성격 증거로 독점하지 않는다.

### 피할 선택과 짧은 예시

`너무 책임감이 강하다`, `일을 너무 잘해서 혼자 한다`는 보완점이 아니다. 진단·건강·가정사 등 민감 정보도 문항 답변에 필요 이상으로 넣지 않는다.

가상 사실 예시: “제 단점은 완벽주의입니다” 대신 “문서 형식을 여러 번 고치느라 공유가 늦었습니다. 다음 작업부터는 검토 항목을 세 개로 정하고 마감 전 중간본을 먼저 보냅니다”라고 쓴다. 후속 공유가 아직 일어나지 않았다면 계획으로 표시한다.

## Q10 윤리·책임

### 실제 질문 요구와 연결

- [FI01](../cases/finance.md#fi01--ibk기업은행-2024-상반기-청년인턴금융일반)은 신뢰 형성 방법과 책임 있게 행동한 경험을 묻는다. 회계 마감·오류 위험·협업의 조건이 윤리 판단의 맥락이다.
- [PA03](../cases/public-admin.md#pa03--경기주택도시공사-2023-상반기-인턴-사무보조)은 공사 직원에게 중요한 직업윤리와 이유를 경험·가치관으로 묻는다. 윤리 정의와 사례를 모두 요구한다.
- [PA05](../cases/public-admin.md#pa05--건강보험심사평가원-표시-연도직무는-현재-열람-본문에서-미확인)은 공직윤리를 직접 묻고, 부족한 전문성을 인정한 뒤 법령 확인·용어 공유 행동을 쓴다.

### 의도와 재료

독자는 `정직` 같은 선언보다 이해관계, 정확성·안전·공익·규정 중 무엇을 지켜야 했는지와 그때의 행동을 본다. 문항이 이유를 요구하면 그 원칙이 왜 해당 직무/상황에서 필요한지 설명한다. 당시 역할·권한, 선택지 또는 압박, 적용한 기준, 실제 행동, 확인된 결과·보고·남은 범위를 받는다. 규정 이름이나 회사 내부 절차는 제공되거나 확인된 사실만 사용한다.

### 가능한 논증 순서

1. 윤리 원칙과 이유 → 원칙과 편의가 충돌한 장면 → 권한 안에서 한 판단·행동 → 확인된 결과.
2. 실수·불확실성 인식 → 확인/보고/보완 행동 → 이후 적용한 기준. 잘못을 숨기지 않되 타인의 개인정보·기밀은 제거한다.

갈등 문항이면 상대 설득과 조정이 중심이고, 윤리 문항이면 기준을 지킨 판단이 중심이다. 같은 안전 점검 경험도 요구에 따라 두 초점을 섞지 않는다.

### 쓰기와 수리

“규정을 준수했습니다”만 있으면 어떤 위험을 보았고 무엇을 확인·보고했는지로 낮춘다. 예를 들어 “기록이 서로 달라 담당자에게 확인한 뒤 수정 전후를 남겼습니다”는 행동을 보이지만, 회사가 실제로 승인했다거나 내부 통제가 있었다고 보태지 않는다. 권한 밖에서 한 조치는 제안·보고로 표시한다.

초안이 영웅담이면 역할과 권한을 다시 대조한다. 결과가 외부 사실·법규 최신성에 의존하면 출처를 확인하거나 결과 주장을 빼고 지원자 행동만 남긴다. 여러 사례가 병렬이면 한 사례를 고르고 원칙과 판단이 보이게 한다.

### 피할 선택과 짧은 예시

무단 야근·규정 우회·개인정보 열람을 일반적인 책임감으로 권하지 않는다. 확인하지 않은 내부 KPI, 감사 결과, 고객 영향, 현행 법·제도를 사실처럼 단정하지 않는다.

가상 사실 예시: “민원 처리율을 높이기 위해 절차를 생략했습니다”는 윤리 근거가 아니다. “기한이 촉박했지만 확인이 필요한 항목을 분리해 담당자에게 전달하고, 답을 받은 뒤 처리했습니다”처럼 속도와 정확성의 판단을 쓴다.
