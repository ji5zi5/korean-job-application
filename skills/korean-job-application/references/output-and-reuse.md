# 최종 본문·요청한 파일·이동 가능한 경험 요약

기본 산출물은 대화에 바로 복사할 수 있는 본문이다. 파일과 이동 가능한 경험 요약은 사용자가 각각 요청한 범위에서만 만들며, 새 외부 조사는 사용자가 명시적으로 요청한 경우에만 한다. 경험 사실의 상태와 작업용 초안의 표식은 [경험 정리·선택과 사실 계약](evidence-and-interview.md), 초안의 충분·부분 입력 기준은 [초안 작성과 직무 맞춤](drafting-and-tailoring.md)을 따른다.

## 본문과 MD/TXT 출력

- 최종 본문만 요청하면 본문만 준다. 요청하지 않은 근거표, 변경 이력, 감사표, 저장 안내를 붙이지 않는다.
- 해결되지 않은 핵심 사실·모순·금지 정보가 본문에 영향을 주면 이를 숨기지 않는다. 이 경우 첫 줄을 `작업용 초안 — 제출 전 확인 필요`로 하고, 제출 완료본이나 제한 충족을 단정하지 않는다.
- 사용자가 MD 또는 TXT 파일을 명시적으로 요청하고 경로를 정했으면 그 정확한 경로와 형식에만 실제 파일을 만든다. 생성 뒤에는 그 정확한 경로를 명시하고 파일을 다시 읽어 내용·형식을 확인한다. 대화에 본문을 보인 일은 파일 생성이 아니다.
- 파일명이나 경로를 정하지 않은 파일 요청은, 저장 위치가 결과에 중대하게 영향을 주거나 안전하지 않거나 의미가 모호하지 않은 한 작업공간에 내용에 맞는 사용되지 않은 파일명을 정해 만든 뒤 정확한 경로를 알린다. 그 밖의 경우에만 필요한 경로 또는 파일명을 확인한다. 같은 위치에 기존 파일이 있으면 내용과 사용자 의도를 확인하고, 덮어쓰기 승인이나 다른 경로를 받기 전에는 바꾸지 않는다.
- MD와 TXT를 둘 다 요청하면 둘 다 실제로 요청된 경로에 만들고 각각 읽어 확인한다. 하나만 요청하면 다른 형식을 덧붙여 만들지 않는다.

## 이동 가능한 경험 요약

요약은 다음 대화나 사용자가 지정한 도구로 옮기기 위한 최소 기록이다. 자동 저장, 세션 간 기억, 프로필 DB 생성·갱신의 동의가 아니다. 사용자가 요약 또는 그 파일을 요청했을 때만 대화 또는 요청 위치에 만든다.

```markdown
# 경험 요약

## 사용자가 확인한 사실
- [경험별 상황 / 본인 역할 / 행동 / 결과·산출물]

## 남은 확인 사항
- [사실, 기간, 역할, 수치, 제약 중 결과를 바꾸는 항목]

## 문항별 사용 이력
- [문항 또는 지원처]: [사용한 경험과 논지] — [완성 초안 / 작업용 초안 / 미사용]

## 요청된 경우의 출처
- [회사·공고 사실]: [출처명, URL, 확인일, 사용 범위]
```

사용자가 제공·확인한 사실만 넣고, 불필요한 식별·민감 정보는 제외한다. 문항별 사용 이력은 사용한 경험을 새 사실처럼 복제하지 않으며, 아직 확인되지 않은 내용은 `남은 확인 사항`에 남긴다. 사용자가 출처 포함을 요청하면 사용자가 제공한 URL 또는 명시적으로 요청해 실제 확인한 회사·공고 출처를 포함한다. 외부 사실을 제시할 때 상위 지침이 출처·인용을 요구하면, 출처 목록을 별도로 요청하지 않았더라도 그 인용을 생략하지 않는다.

## 전문 문서 형식 요청

DOCX, HWP, HWPX, PDF는 현재 이용 가능한 전용 문서 형식 스킬이 해당 형식을 실제로 생성·검증할 수 있을 때만 처리한다. 그 스킬의 실제 형식 지원과 결과물 검증 절차를 따른 뒤, 생성된 정확한 파일 경로와 확인 결과를 알린다.

현재 전용 도구가 없거나 실제 형식 지원·검증이 불가능하면 성공했다고 말하지 않는다. 확장자만 바꾸거나 MD/TXT를 해당 형식으로 위장해 만들지 않으며, 가능하면 사용자가 요청한 범위 안에서 대화 본문 또는 MD/TXT를 대안으로 제안한다.
