# 출처와 지식 색인

이 문서는 출처·구성·수량을 확인하거나 관련 근거를 찾을 때만 읽는다. 일반 초안이나 좁은 첨삭에서 전체 색인을 불러오지 않는다.

## 자료의 지위와 사용 한계

- 일반 작법 P01–P09는 공공 취업 안내, 해외 채용 주체·대학 안내를 한국어 자소서 판단에 제한적으로 적용한 원칙이다. 출처가 지원자의 경험이나 합격 효과를 증명하지 않는다.
- 공개 사례 30편은 2026-09-06에 공개 페이지의 문항과 답변 본문을 읽고 짧게 분석한 기록이다. `합격 자소서`는 게시 플랫폼의 표시일 뿐 고용주 확인, 글의 품질, 채용 인과를 뜻하지 않는다. 답변 속 회사·시장·제도 설명은 현재 사실의 출처가 아니다.
- 사용자가 제공한 경험·공고 요약은 작성 입력으로 쓸 수 있지만 독립 검증된 원문이라고 부르지 않는다. 현재 회사 사실이 필요하면 별도 원출처와 날짜를 확인한다.
- 공개 답변의 문장이나 지원자 프로필을 복제하지 않는다. 필요한 관찰만 짧게 바꾸어 쓰고 원문 링크를 남긴다. 외부 자료의 인용·요약은 해당 도구의 저작권·출처별 단어 제한을 지킨다.
- 아래 합성 시연과 수리 카드의 전후 예시는 독자적으로 만든 교육용 자료다. 실제 합격 사례, 합격 보장, AI 저작성 또는 탐지 회피의 증거가 아니다.
