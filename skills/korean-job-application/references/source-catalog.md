# 출처와 지식 색인

이 문서는 출처·구성·수량을 확인하거나 관련 근거를 찾을 때만 읽는다. 일반 초안이나 좁은 첨삭에서 전체 색인을 불러오지 않는다.

## 자료의 지위와 사용 한계

- 일반 작법 P01–P09는 공공 취업 안내, 해외 채용 주체·대학 안내를 한국어 자소서 판단에 제한적으로 적용한 원칙이다. 출처가 지원자의 경험이나 합격 효과를 증명하지 않는다.
- 공개 사례는 **전문가 고평점 10편 + 저평점 4편 + 기존 문항 관찰 30편**, 총 44개 고유 URL이다. 모두 2026-09-06에 확인했다. 기존 30편은 링커리어 22편·잡코리아 8편이며 고평점 선별 자료가 아니었다. 잡코리아 기존 3편의 전문가 평가를 재확인해 개선용/좋은 대목/부분 수정으로 구분했다.
- `합격 자소서`는 플랫폼의 표시이고, 전문가 별점도 해당 글에 대한 외부 평가다. 특정 대목의 품질은 문항·답변·개별 첨삭을 대조한다. 둘 다 고용주 확인이나 합격 원인을 뜻하지 않으며, 답변 속 회사·시장·제도 설명은 현재 사실의 출처가 아니다.
- 사용자가 제공한 경험·공고 요약은 작성 입력으로 쓸 수 있지만 독립 검증된 원문이라고 부르지 않는다. 현재 회사 사실이 필요하면 별도 원출처와 날짜를 확인한다.
- 공개 답변의 문장이나 지원자 프로필을 복제하지 않는다. 필요한 관찰만 짧게 바꾸어 쓰고 원문 링크를 남긴다. 외부 자료의 인용·요약은 해당 도구의 저작권·출처별 단어 제한을 지킨다.
- 아래 합성 시연과 수리 카드의 전후 예시는 독자적으로 만든 교육용 자료다. 실제 합격 사례, 합격 보장, AI 저작성 또는 탐지 회피의 증거가 아니다.

## 전문가 평가 분석과 대조 작법

[ER01–ER14 원문 분석](cases/expert-reviewed.md)은 고평점 4~5점 10편과 저평점 1~2점 4편의 총평·문항별 첨삭을 함께 확인한 자료다. 점수·URL·시기·직무·문항 맥락·전문가 판단·스킬의 적용 판단을 구분했다. [D01–D06 대조 작법](expert-writing-decisions.md)은 좋은/부족한 대목, 표현·구조·근거 부족의 수정 수준과 동일 사실의 전후 시연을 실제 초안·첨삭 판단에 연결한다. 저평점도 합격자소서 게시물로서 글의 평가가 낮은 것이며, 탈락 사례나 지원자의 능력 평가로 바꾸어 말하지 않는다.

사례를 더 추가할 때도 이 구분을 유지한다. 고평점은 탐색 우선순위이고, **좋은 사례 채택에는 그 대목을 긍정한 이유와 원문의 실제 근거가 함께 필요**하다. 비판받은 대목은 개선용으로 쓴다. 평가 미확인은 0점이나 나쁜 글이 아니라 품질 선별 보류이며, 문항 관찰에만 쓴다. 평자 의견과 답변이 충돌하면 보류하고, 제목·본문의 회사/직무 불일치는 해소 전 핵심 우수 사례에서 제외한다. 평가 개수나 직무별 할당량을 채우려고 이를 완화하지 않는다.
