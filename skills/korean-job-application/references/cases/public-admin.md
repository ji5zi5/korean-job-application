# 공공·행정 공개 지원서 사례 5건

열람일: 2026-09-06. 공개 페이지의 질문·답변과 확인 가능한 전문가 평가를 읽어 요약했다. `전문가 평가`는 잡코리아의 총평·문항별 평을, `우리의 적용`·`한계와 수리`는 이 스킬의 해석을 뜻한다. 원문 전체·지원자 프로필·식별 정보는 저장하지 않는다. `합격자소서`는 페이지 분류이며, 전체 별점이 모든 문항의 품질이나 합격 원인을 뜻하지 않는다. 과거 기관·제도·직무 내용은 현행 공고나 규정의 근거가 아니다.

중복 점검: 회사·표시 연도·직무·URL·선택 문항을 대조했으며, 한 URL의 복수 문항을 여러 지원서로 세지 않았다. 유형 연결은 실제 질문의 하위 요구가 있을 때만 했다.

## PA01 — 한국조폐공사, 2019 상반기 신입 사무담당자

- 원문: <https://www.jobkorea.co.kr/starter/passassay/View/198750> (잡코리아, 2026-09-06 열람). 페이지가 `합격자소서`와 2019 상반기·신입 사무담당자를 표시한다; 이는 플랫폼 표지다.
- 읽은 문항·답변: 원문 Q2, “최근 3년간 본인이 경험한 가장 어려웠던 일을 기술하고 이후의 과정과 결과에 대해 말씀해 주십시오.” 답변은 자격시험의 반복 불합격 뒤 오답 유형을 분석해 다시 준비한 과정을 다룬다. 유형: Q06 실패·회복.
- 전문가 평가: 전체 별점 **2개**. 총평은 회사·직무에 맞춘 강점이 약하고 범용적인 내용이라고 지적한다. Q2에서는 자격 취득 과정을 길게 설명해도 직무상 강점이 추가되지 않으며, 가장 어려운 일이라는 선택이 설득력을 낮춘다며 다른 소재를 권한다.
- 우리의 적용 — 개선·반례: 회복 과정의 순서만 갖췄다고 좋은 실패 경험이 되지 않는다. 먼저 문항의 난도와 직무에 맞는 소재로 바꿀지 판단한다. `P01`, `P05`; `QF05`, `CA05`, `EV03`으로 경험 적합성과 이후 행동을 확인한다.

## PA02 — 한국동서발전, 2019 하반기 신입 사무담당자

- 원문: <https://www.jobkorea.co.kr/starter/PassAssay/View/201824> (잡코리아, 2026-09-06 열람). 페이지가 `합격자소서`와 2019 하반기·신입 사무담당자를 표시한다; 이는 플랫폼 표지다.
- 읽은 문항·답변: 원문 Q5, “본인이 속한 조직 또는 팀에서 발생한 갈등을 중재해 본 경험이 있습니까?” 하위 요구는 중재 원칙·기준과 당사자 설득 방법이다(100~500자). 답변은 교육봉사 자리 다툼에 대해 평등한 참여 기준, 당사자 회의, 배치 변경과 추첨을 사용한다. 유형: Q05 갈등.

- 우리의 적용 — 긍정 문항: Q5는 전체 별점과 구분해 참고한다. 중재 원칙과 실제 조정 절차를 함께 제시해 질문의 하위 요구에 답한 점을 적용한다.
- 한계와 수리: 모든 중재에 추첨·배치 변경이 맞는 것은 아니며, 설득 과정의 반대 의견과 결과 범위가 적다. `P04`, `P08`; `CO06`, `EV02`, `CA01`로 이해관계·본인 행동·결과를 분리한다.
