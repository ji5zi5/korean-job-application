# 영업·마케팅·서비스 공개 사례

이 자료는 실제 공개 지원서의 **문항과 해당 답변을 직접 읽은** 짧은 관찰 기록이다. 직무군은 답변 주제가 아니라 원문 페이지의 직무 라벨로 분류한다. 답변 전문·지원자 프로필을 보관하지 않으며, 플랫폼의 `합격 자소서` 표시는 고용주 결과나 글의 품질을 검증하지 않는다.

## SS01 — E1 / 국내영업 / 2025 하반기

- 원문: <https://linkareer.com/cover-letter/36234> · 열람일: 2026-09-06 · 직무 라벨: 국내영업 · 공개 상태: 페이지의 `합격 자소서` 라벨 확인(고용주 결과는 미검증).
- 실제 문항 유형: Q01 지원동기, Q02 직무역량, Q04 협업, Q08 가치관. 다섯 문항 중 관련 문항·답변을 읽었다.
- 관찰: 회사 선택 기준을 먼저 밝히고 회사가 제공한다고 보는 가치와 영업 역할을 잇는다. 편의점 발주 사례는 관찰 기간·조건·변화를 써서 강점을 행동으로 보이며, 팀 이견에는 일정과 리소스를 시각화해 중재 역할을 구체화한다.
- 한계: 회사의 안전·공급 관련 표현과 각 성과 수치는 별도 출처·비교 기준 없이 현재 사실 또는 유일한 인과로 쓰지 않는다. 조직문화 평가는 개인의 선호로만 남긴다.
- 연결: P01, P03, P04, P05, P06 / EV04, EV06, CO03, CA01.

## SS02 — KCC 실리콘 / 국내영업 / 2024 하반기

- 원문: <https://linkareer.com/cover-letter/34386> · 열람일: 2026-09-06 · 직무 라벨: 국내영업 · 공개 상태: 페이지의 `합격 자소서` 라벨 확인(고용주 결과는 미검증).
- 실제 문항 유형: Q01 지원동기, Q02 직무역량, Q07 도전·목표, Q08 성장과정·가치관. 네 문항과 답변을 읽었다.
- 관찰: 성장·강점 문항에서 고객 대기 문제를 발견한 뒤 여러 공급업체를 비교하고 직원과 선택한 과정을 배치한다. 도전 문항은 설문 QR, 피드백 반영, 운영 변경이라는 본인 제안을 분리해 쓴다.
- 한계: 재방문율·매출 증가는 기간과 측정 주체를 추가 확인해야 하며, 회사의 기술·환경 주장은 당시 자료가 아닌 이상 현행 근거로 재사용하지 않는다. 수업 프로젝트의 가정 수치는 실무 성과로 바꾸지 않는다.
- 연결: P01, P04, P05, P06, P08 / EV04, CO03, CA01, CA03.

## SS03 — 하나머티리얼즈 / 국내영업 / 2023 상반기

- 원문: <https://linkareer.com/cover-letter/32824> · 열람일: 2026-09-06 · 직무 라벨: 국내영업 · 공개 상태: 페이지의 `합격 자소서` 라벨 확인(고용주 결과는 미검증).
- 실제 문항 유형: Q01 지원동기, Q08 성장과정·가치관, Q09 성격 장단점. 세 문항과 답변을 읽었다.
- 관찰: 성장 과정은 가족의 직업관을 현재 가치의 배경으로만 쓰고, Q09에서는 경청·꼼꼼함을 상세페이지 분석·전표 확인 행동으로 붙인다. 느린 처리라는 단점도 일정 기록과 마감으로 조정하려는 행동을 제시한다.
- 한계: 체류시간 변화는 원인·기간·측정 조건이 부족하고, 지원동기 답변의 마케팅 표현은 페이지의 국내영업 직무 라벨을 바꾸는 근거가 아니다. 가족 경험을 본인 역량의 증명으로 과장하지 않는다.
- 연결: P02, P03, P05, P08, P09 / QF06, EV04, CA01, IN02.

## SS04 — 두산그룹 / 유통BU MD / 2022 상반기

- 원문: <https://linkareer.com/cover-letter/30633> · 열람일: 2026-09-06 · 직무 라벨: 유통BU MD · 공개 상태: 페이지의 `합격 자소서` 라벨 확인(고용주 결과는 미검증).
- 실제 문항 유형: Q01 지원동기(회사·직무 이유). 해당 문항과 답변을 읽었다.
- 관찰: 약국 아르바이트에서 할 수 있었던 범위와 할 수 없었던 범위를 구분한 뒤, 진열·홍보 문구·고객 응대에서 배운 점을 유통/MD 관심으로 연결한다. 서비스 경험을 직무 적합성의 근거로 고르는 작은 소재 사례다.
- 한계: 현장 경험은 회사 선택 이유보다 직무 관심을 더 잘 설명한다. 회사의 시장 평가와 매출 영향은 근거 없이 넓히지 않으며, 제품 설명 권한이 없었다는 경계도 지운 채 쓰지 않는다.
- 연결: P01, P02, P04, P06 / QF06, CO04, EV06, CL06.

## SS05 — 슈피겐코리아 / 해외영업(인도) / 2020 하반기

- 원문: <https://linkareer.com/cover-letter/26069> · 열람일: 2026-09-06 · 직무 라벨: 해외영업(인도) · 공개 상태: 페이지의 `합격 자소서` 라벨 확인(고용주 결과는 미검증).

- 관찰: Q09에서 현장 고객 관찰 뒤 본사와 조율한 판매 제안을 장점의 근거로 쓰고, 조급함으로 생긴 자료 누락을 달력·재확인 습관으로 조정한다. 벤더별 변경사항을 정리해 확인 횟수를 줄인 경험은 영업의 사후관리 연결에 활용한다.
- 한계: 과거 회사 시장점유율·조직 현황은 현행 사실로 사용하지 않는다. 판매 품절·업무 효율의 결과는 다른 요인의 영향을 분리하지 못하므로 단일 행동의 효과로 단정하지 않는다.
- 연결: P03, P04, P05, P06, P08 / EV04, EV06, CA01, CA06.
